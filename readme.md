# 🚀 Local Space RAG Assistant with Ollama, LlamaIndex, and Streamlit

This project is a fully local **Retrieval-Augmented Generation (RAG)** application for asking questions over space-related documents.

It allows users to place local text or PDF documents into a `data/` folder, build a vector index, and ask questions through either a command-line interface or a Streamlit web app.

The project runs locally using **Ollama**, so it does **not** require an OpenAI API key or any paid cloud LLM service.

---

## 🌌 Project Overview

This application implements a complete local RAG pipeline:

1. 📄 Load local documents from the `data/` folder.
2. 🧠 Convert documents into vector embeddings using a local embedding model.
3. 🗂️ Build and persist a vector index with LlamaIndex.
4. 🔍 Retrieve relevant document chunks based on the user question.
5. 🤖 Generate an answer using a local Ollama language model.
6. 📚 Display the answer and retrieved source documents in a Streamlit web interface.

The goal of this project is to demonstrate how to build a private, local, document-grounded question-answering system without relying on external LLM APIs.

## 🧠 Model Setup

This project uses **Ollama** to run language and embedding models locally.

### 🤖 Local Language Model

```bash
ollama pull llama3.2:3b
```

`llama3.2:3b` is used as the local language model for generating answers.

### 🧬 Local Embedding Model

```bash
ollama pull nomic-embed-text
```

`nomic-embed-text` is used to convert document text and user questions into vector embeddings for semantic retrieval.

Both models run locally through Ollama. No OpenAI API key is required.

## 📄 How to Use

### Step 1: Add documents

Place your local space-related documents inside the `data/` folder.

Example:

```text
data/
├── space_1.txt
├── nasa_mission_notes.txt
├── planets.txt
└── astronomy_article.pdf
```

The documents can include topics such as:

* 🚀 Space exploration
* 🪐 Planets and moons
* 🌌 Galaxies
* 🕳️ Black holes
* 🛰️ NASA missions
* 🌕 Lunar exploration
* 🔭 Astronomy notes
* 👨‍🚀 Human spaceflight

Supported formats depend on LlamaIndex readers. Text files work directly. PDF support requires `pypdf`.

---

## 🏗️ Step 2: Build the index

Run:

```bash
python ingest.py
```

This will:

* Load documents from the `data/` folder.
* Convert text into embeddings using `nomic-embed-text`.
* Build a vector index with LlamaIndex.
* Save the index into the `storage/` folder.

You need to rerun `ingest.py` whenever you add, remove, or modify documents in the `data/` folder.

---

## 💬 Step 3: Query from the command line

Run:

```bash
python query.py
```

Then enter a question, for example:

```text
What are the main topics discussed in these space documents?
```

The system will return:

* ✅ An answer generated by the local LLM.
* 📚 Retrieved source documents used to support the answer.

---

## 🎈 Step 4: Run the Streamlit app

Run:

```bash
streamlit run app.py
```

If this does not work in your environment, use:

```bash
python -m streamlit run app.py
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:8501
```

---

## 🖥️ Streamlit App Behavior

The Streamlit app allows users to type a question into a web interface.

The app will:

1. 🔍 Retrieve relevant chunks from the local document index.
2. 🤖 Send those chunks to the local Ollama LLM.
3. ✍️ Generate an answer based on the retrieved context.
4. 📚 Display retrieved source documents below the answer.

The app is designed as a **document-grounded assistant**. It is not a general chatbot. If the answer is not supported by the retrieved documents, the app may say that the documents do not contain enough information.

## 🧯 Troubleshooting

### 1. `llama_index` module not found

Install the required packages:

```bash
pip install -r requirements.txt
```

Or install them manually:

```bash
pip install streamlit llama-index llama-index-llms-ollama llama-index-embeddings-ollama pypdf
```

### 2. Ollama model not found

Make sure the required models are downloaded:

```bash
ollama pull llama3.2:3b
ollama pull nomic-embed-text
```

Check installed models:

```bash
ollama list
```

### 3. Streamlit does not run

Use:

```bash
python -m streamlit run app.py
```

### 4. Model requires too much memory

Local models require system memory. If `llama3.2:3b` causes memory issues, reduce the context window in the code or use a smaller model.

For example:

```bash
ollama pull llama3.2:1b
```

Then update the model name in the code:

```python
model="llama3.2:1b"
```

### 5. The app says it cannot answer the question

This usually means the retrieved documents do not contain enough relevant information.

Try asking a question that is more directly related to the documents in the `data/` folder.

For example, instead of:

```text
Who are you?
```

Ask:

```text
What does the document say about Mars exploration?
```

## 🧠 How RAG Works in This Project

The application follows the RAG workflow:

```text
User Question
      ↓
Embedding Model
      ↓
Vector Search
      ↓
Relevant Document Chunks
      ↓
Local LLM
      ↓
Grounded Answer + Sources
```

The key idea is that the LLM does not answer only from its internal knowledge. Instead, it first receives relevant text chunks retrieved from the local document index.

This makes the answer more grounded, transparent, and document-specific.
